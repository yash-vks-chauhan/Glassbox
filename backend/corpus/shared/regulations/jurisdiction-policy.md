# Jurisdiction Review

Client jurisdiction constraints must be taken from the client's approved IPS.
A cross-border recommendation should be reviewed against every jurisdiction documented in the client's IPS.
If a recommendation involves a jurisdiction that is not documented in the client's IPS, the advisor should escalate to Compliance before presenting the recommendation.
The advisory note should cite both the client IPS jurisdiction sentence and this jurisdiction review policy.
