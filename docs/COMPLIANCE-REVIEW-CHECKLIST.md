# Compliance Review Checklist

Use this checklist when Compliance reviews a GlassBox decision replay.

## Decision Context

- Confirm the client ID, question, advisor, and timestamp.
- Confirm the outcome is answered, flagged, refused, or fallback as expected.
- Confirm the model route and timing metadata are present.
- Confirm the escalation status if review was requested.

## Evidence Review

- Check that retrieved IPS evidence matches the client.
- Check factsheet evidence for fund-specific claims.
- Check suitability guidance for recommendation questions.
- Verify percentages, limits, floors, exclusions, and concentration claims.

## Review Outcome

- Approve the advisor action only if the cited evidence supports it.
- Request more evidence when support is weak or missing.
- Document any exception path before client action.
