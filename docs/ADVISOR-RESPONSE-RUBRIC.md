# Advisor Response Quality Rubric

Use this rubric when reviewing advisor-facing GlassBox answers.

## Required Qualities

- Starts with a direct decision such as yes, no, or needs review.
- Gives a short reason in advisor-readable language.
- Includes citations for material claims.
- Provides a clear next action.
- Avoids phrases like "as an AI" or unsupported legal disclaimers.

## Failure Patterns

- Repeats the same claim more than once.
- Cites the right source ID but the text does not support the claim.
- Explains internal model behavior instead of advisor action.
- Gives a recommendation when evidence is missing.
- Omits escalation for flagged or refused decisions.

## Scoring Notes

A model route should not pass advisor quality if the answer is correct but hard for an advisor to use under time pressure.
